# Figma Implement Validation

## 구현 후 검증

코드 수정이 끝나면 가능한 범위에서 아래를 확인한다:

- 수정한 파일이 스펙의 상태/변경 파일과 실제로 대응하는가
- 새 분기나 상태가 누락되지 않았는가
- obvious regression이 없는지 관련 테스트, 타입체크, 린트, 또는 최소 실행 확인을 한다

검증 명령이 명확하면 실행하고, 명확하지 않으면 최소한 수동 점검 결과를 보고한다.

보고 시 함께 남길 내용:

- 실행한 검증 명령
- 통과/실패 여부
- 실행하지 못했다면 그 이유

## 구현 완료 보고 템플릿

```
## 구현 완료 보고

### 구현 결과
- 생성/수정된 파일 목록

### 스펙 대비 변경 사항
스펙을 그대로 따르지 않고 다르게 구현한 항목. 없으면 "없음".

| 스펙 내용 | 실제 구현 | 변경 이유 |
| --------- | --------- | --------- |
| width: 347px (base.md > Section A) | w-full | 컨테이너 결과값으로 판단, 반응형 대응 |
| gap: 18px (base.md > Header) | gap-4 (16px) | Tailwind 기본 스케일에 매핑, 2px 차이 |

### 스펙에 없지만 추가한 항목
접근성, UX 관행 등으로 추가한 요소. 없으면 "없음".

- 키보드 포커스 링 추가 (Button, Input)
- aria-label 추가 (아이콘 버튼)

### 미구현 항목
스펙에 있지만 구현하지 않은 항목. 없으면 "없음".

- [ ] hover 상태 — unknowns.md에 "프레임 없음"으로 기록됨, 디자이너 확인 필요
```
