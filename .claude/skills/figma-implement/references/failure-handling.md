# Figma Implement Failure Handling

## 목적

`figma-implement` 실행 중 blocker 또는 품질 저하 위험이 생길 때의 상세 처리 규칙이다.

## 대표 blocker / 예외 케이스

### 스펙 파일끼리 충돌

- `index.md`와 개별 스펙 파일의 내용이 다르면, 더 구체적인 파일을 우선 확인한다
- 그래도 해소되지 않으면 코드를 먼저 바꾸지 말고 스펙 충돌로 보고한다

### unknowns가 blocker로 승격

- 처음엔 구현 가능해 보였더라도, 실제 코드 작성 중 필수 정보가 비었다고 판단되면 blocker로 승격한다
- 이 경우 해당 항목을 `unknowns.md`에 갱신하고, 필요한 최소 범위만 재조회한다

### 로컬 토큰으로 처리 불가

- `scope: local`로 시작했지만 실제 구현상 전역 디자인 시스템 수정이 필요해지면, 임의로 전역 수정하지 않는다
- `global_candidates`로 올리고 사용자 승인 전까지는 로컬 범위에서만 마무리한다

### 스펙대로 구현하면 품질이 떨어짐

- 반응형, 접근성, 성능 문제 때문에 스펙을 그대로 따르기 어려우면 합리적으로 조정한다
- 단, 그 차이는 반드시 최종 보고의 "스펙 대비 변경 사항"에 기록한다
